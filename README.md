
# SkillMatrix

Employee Skill Management System using Python, Flask and SQLite.

## Project Features

- Employee Management
- Learning Goals Management
- Employee Progress Tracking
- Skill Gap Analysis
- Training Recommendations
- Reports and CSV Export
- Dashboard Overview

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

## How to Run

1. Install Python.
2. Install Flask:
   pip install flask
3. Open the web application folder in VS Code.
4. Run the application:
   python app.py
5. Open your browser:
   http://127.0.0.1:5000
